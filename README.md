# Kinopoisk Microservices

Микросервисная система управления контентом в стиле Kinopoisk, разработанная как курсовая работа по дисциплине "Сервис-ориентированное программирование". Проект демонстрирует современный подход к построению распределенных систем с использованием различных паттернов и технологий взаимодействия между сервисами.

## Архитектура

### Системная архитектура
```
┌─────────────────┐     gRPC        ┌──────────────┐
│ Kinopoisk       │───────────────▶│ User         │
│ Service         │◀───────────────│ Service      │
│ (REST/GraphQL)  │                 │ (gRPC)       │
└────────┬────────┘                 └──────┬───────┘
         │                                 │
         │ RabbitMQ (Topic/Fanout)         │ RabbitMQ (Fanout)
         ▼                                 ▼
┌─────────────────┐                ┌─────────────────┐
│ Audit           │                │ Notification    │
│ Service         │                │ Service         │
│ (Логирование)   │                │ (WebSocket)     │
└─────────────────┘                └─────────────────┘
```

### Коммуникационные паттерны
1. **Синхронное взаимодействие (gRPC)**
   - `kinopoisk-service` → `user-service`: запросы оценок и рецензий
   - Low-latency, strict contracts, binary protocol

2. **Асинхронное взаимодействие (RabbitMQ)**
   - **Topic Exchange**: События CRUD операций (создание/удаление контента и персон)
   - **Fanout Exchange**: Широковещательные события (оценки, рецензии)
   - Publisher/Subscribe, Event-driven architecture

3. **Real-time уведомления (WebSocket)**
   - Двусторонняя связь для мгновенных уведомлений
   - Подписка на события через RabbitMQ Fanout

## Микросервисы

| Сервис | Порт | Технологии | Назначение |
|--------|------|------------|------------|
| **kinopoisk-service** | 8081 (8080 внутр.) | Spring Boot, REST, GraphQL, HATEOAS | Основной API для управления контентом (фильмы, сериалы) и персонами (актеры, режиссеры) |
| **user-service** | 9091 (9090 внутр.) | gRPC, Protobuf | Управление пользовательскими данными: оценки, рецензии, избранное |
| **audit-service** | 8082 | Spring Boot, RabbitMQ | Централизованное логирование всех событий системы через RabbitMQ |
| **notification-service** | 8083 | WebSocket, RabbitMQ | Real-time уведомления для клиентов через WebSocket |
| **Инфраструктура** | | | |
| rabbitmq | 5672, 15672 | RabbitMQ Management | Брокер сообщений для асинхронной коммуникации |
| zipkin | 9411 | Zipkin | Распределенная трассировка запросов |
| prometheus | 9090 | Prometheus | Сбор и хранение метрик |

## Технологический стек

### Backend
- **Java 21** + **Spring Boot 3.5.6**
- **Spring Framework**: Web, Data, Security (готовность к расширению)

### API и Протоколы
- **REST API** (HATEOAS): Основной HTTP интерфейс с гипермедиа
- **GraphQL** (Netflix DGS): Гибкие запросы для клиентов
- **gRPC** + **Protocol Buffers**: Высокопроизводительное межсервисное взаимодействие
- **WebSocket**: Двусторонняя реальная связь

### Message Brokers и Очереди
- **RabbitMQ**: Асинхронная коммуникация
  - **Topic Exchange**: Фильтруемая маршрутизация событий
  - **Fanout Exchange**: Широковещательная рассылка
  - Publisher Confirms, Dead Letter Queue (отказоустойчивость)

### Наблюдаемость (Observability)
- **Micrometer Tracing** (Brave): Распределенная трассировка
- **Zipkin**: Визуализация трейсов
- **Prometheus** + **Actuator**: Сбор метрик
- **Logback JSON encoder**: Структурированное логирование с TraceId/SpanId

### Контейнеризация и Оркестрация
- **Docker**: Контейнеризация всех сервисов
- **Docker Compose**: Оркестрация локального развертывания
- Health checks, depends_on, сетевые политики

### Архитектурные паттерны
1. **Микросервисная архитектура**: Разделение ответственности
2. **CQRS**: Разделение чтения и записи (готовность к масштабированию)
3. **Event-Driven Architecture**: Событийно-ориентированная коммуникация
4. **API Gateway**

### Структура проекта
```
kinopoisk-microservices/
├── services/                   # Бизнес-микросервисы
│   ├── kinopoisk-service/      # Главный API (REST/GraphQL/HATEOAS)
│   ├── user-service/           # gRPC сервис пользовательских данных
│   ├── audit-service/          # Логирование и аудит событий

│   ├── events-contract/        # События RabbitMQ
│   ├── kinopoisk-api-contract/ # REST API модели

├── docker-compose.yml          # Оркестрация всех сервисов
├── prometheus.yml             # Конфигурация сбора метрик
├── .gitignore                 # Исключения Git
└── README.md                  # Документация
```
